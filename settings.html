API 配置

Embedding API

Embedding 服务的 OpenAI 兼容接口地址，通常填写到 /v1 之前或 /v1。
用于调用 Embedding 服务，仅保存在 SillyTavern 扩展设置中。
生成聊天和世界书向量的模型名称。
从接口返回的模型列表中选择 Embedding 模型。

Reranker API

Reranker 服务地址；留空整组配置即可只使用向量排序。
用于调用 Reranker 服务的密钥。
对向量召回候选进行相关性精排的模型名称。
从接口返回的模型列表中选择 Reranker 模型。

弹幕副 API

生成弹幕的 OpenAI 兼容接口地址，与主聊天 API 相互独立。
用于调用弹幕副 API 的密钥。
负责生成弹幕文本的模型名称。
从接口返回的模型列表中选择弹幕模型。

每个聊天向量块包含的消息条数。较小更精确，较大可保留更多上下文。
向量搜索初步召回的候选数量。数值越大召回更全面，但处理更慢。
最终发送给 AI 的记忆片段上限，应不大于 top-K。
精排结果的最低相关度，越高越严格；未配置 Reranker 时不生效。
