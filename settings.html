API 配置

Embedding API

Embedding 服务的 OpenAI 兼容接口地址，通常填写到 /v1 之前或 /v1。

Reranker API

Reranker 服务地址；留空整组配置即可只使用向量排序。
用于调用 Reranker 服务的密钥。
对向量召回候选进行相关性精排的模型名称。
从接口返回的模型列表中选择 Reranker 模型。

弹幕副 API

生成弹幕的 OpenAI 兼容接口地址，与主聊天 API 相互独立。
用于调用弹幕副 API 的密钥。

从接口返回的模型列表中选择弹幕模型。
