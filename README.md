# KKToolbox

给 SillyTavern 使用的记忆增强工具箱。

## 能做什么

- **自动总结**：总结较早的聊天，并保留最近楼层原文。
- **聊天记忆**：从前文找回与当前剧情相关的历史片段。
- **世界书语义检索**：按内容含义查找手动勾选的世界书条目。
- **记忆库管理**：查看、搜索、修改或禁用当前聊天的记忆片段。
- **弹幕与剧情状态**：使用独立 API 生成观众弹幕和可拖动的剧情状态栏；两项可分别开关，同时开启时只请求一次。
- **人物发展档案**：区分临时情绪与长期变化；玩家明确设定立即生效，普通变化会先观察再确认。
- **世界地图册**：从当前角色的世界书一键生成可点击的地点关系图，支持子地图、备注、连接线和手动编辑。
- **HTML 兼容渲染**：让世界书或正则替换生成的 HTML 代码块显示为可交互界面，不修改聊天原文。

## 安装

在 SillyTavern 的扩展管理中选择“安装扩展”，粘贴本项目的 GitHub 地址并确认。

## 使用

1. 点击顶部工具箱图标。
2. 填写 Embedding API 的地址、Key 和模型。
3. 按需要配置 Reranker、弹幕和其他选项。
4. 正常聊天即可。

Embedding 是聊天记忆的必需配置；Reranker 和弹幕副 API 可以留空。

## 数据

聊天记忆、向量、摘要、弹幕、剧情状态和人物发展档案保存在当前 SillyTavern 用户数据中。需要生成向量、精排、弹幕、剧情状态或人物发展判断时，相关文本会发送到你填写的 API 服务商。
